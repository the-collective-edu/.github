# The Collective

An open, volunteer-run coalition of school IT professionals building and freely sharing AI runtimes, automations, scripts, and infographics for education.

Everything here is free to use, adapt, and reuse. Code is MIT-licensed; other content is CC BY 4.0.

This org is newly stood up. The [toolbox](https://github.com/the-collective-edu/toolbox) repo holds prompts, scripts, and notes as they're contributed — more is coming.

Independent of any single member's employer. No real student data appears anywhere in this org.
